What it is

One workspace for the whole writing loop.

Six parts of the job that usually live in six different tools.

LaTeX-aware editing

Autocomplete for commands, environments, labels and citation keys, snippets with placeholders, automatic \end{…}, comment toggle and text commands.

Source beside the page

Live PDF preview with zoom, page navigation and in-document search. Two-way SyncTeX jumps between a source line and its exact rectangle on the page.

Builds you can read

Choose the engine per project, watch the live log, jump from a compiler error to the line, and install a missing TeX package and rebuild in one step.

References that stay honest

A bibliography manager tells you which keys are cited, which entries nobody uses and which citations have no entry at all — then inserts the citation for you.

Research tools in reach

Per-project word goals, project-wide TODO/FIXME tracking, private notes, document statistics and a numbered table of contents that mirrors the final PDF.

Nothing gets lost

Every saved version stays in a local change history with a line diff and one-click restore. Snapshots capture whole projects before a rewrite; ZIP and GitHub import move them around.

    Run it yourself

    Up in two commands.

    Node.js 18+ and npm. TeX Live or MiKTeX for compilation — or compile in the browser on the hosted build.

    Privacy by design

    Your documents never leave your machine.

    There is no LaTeX Studio account and no upload step. Projects live in your own folders, history and snapshots are stored in your browser, and the Zotero key you enter stays on your device. The hosted build serves only static assets — and then your sources and PDFs stay in that browser.

    Questions

    Short answers.

    Where are my files stored?

    On the local server under projects/, or — on the hosted version — in your browser's IndexedDB. The Worker only serves static assets.

    Do I need a TeX installation?

    For the desktop server: yes, TeX Live or MiKTeX for compilation and package checks. The hosted build compiles pdfLaTeX and XeLaTeX in WebAssembly instead.

    How do citations work?

    The bibliography manager lists every entry of your .bib files, shows which keys the document cites and which citations have no entry. Import a Zotero / Better BibTeX export, browse your Zotero library live, and insert \cite{…} from the panel or the autocomplete.

    Can I go back after a bad edit?

    Yes. The change history keeps every saved version of a file — open it from the project menu to see a line diff and restore any version. Snapshots additionally capture whole projects before a rewrite.

    How do I track my writing progress?

    Open the research panel (Alt+T): set a word goal per project, watch the progress bar fill across all files, filter open TODO/FIXME notes, and keep project notes in the same place.

    Can I link to a specific document?

    Yes — /studio?project=Paper&file=chapters/intro.tex&line=42 opens that project, file and line directly. The project cards on this page use the same mechanism.

    Is there a distraction-free mode?

    Press Alt+Z for focus mode. The editor stays centered while the sidebar, preview and console disappear.

    Can two people edit the same project?

    Connected editors on the same local server see each other and receive saved changes immediately; unsaved local edits are never overwritten. It is a work-in-progress feature, not internet multiplayer.
