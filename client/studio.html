LaTeX Studio

A local LaTeX editor with a live preview, SyncTeX, and autocomplete.

  • Ctrl+click in the PDF → jump to source (SyncTeX)
  • Ctrl+Shift+G → jump to the current line in the preview
  • Ctrl+Space → autocomplete, Ctrl+E → environments
  • Project menu ⋯ → rename, duplicate, import or export ZIP

Connect Zotero

      
Browse a Zotero library here and keep it updated automatically. The connection is read-only; this browser sends requests directly to Zotero.

      

        
        
        
        
Create a key with read access only in Zotero’s key settings. It is stored in this browser’s local database and sent directly to Zotero. Enable file access if you want to preview PDF attachments.
